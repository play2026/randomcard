Random Cards - iPhone Offline PWA

Upload ALL files in this folder to the SAME GitHub Pages folder:
- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png

IMPORTANT FOR IPHONE:
1. Open the GitHub Pages URL in Safari while online.
2. Wait for the page to finish loading. The page may reload once automatically so the service worker controls it.
3. Close the Safari tab and open the same URL again once while still online.
4. In Safari Share -> Add to Home Screen -> Open as Web App -> Add.
5. Launch Random Cards from the Home Screen while online once.
6. Close the app completely. Turn on Airplane Mode and open it again from the Home Screen.

Do not use a github.com/.../blob/... or raw.githubusercontent.com URL. Use the actual https://USERNAME.github.io/... GitHub Pages URL.
