Random Cards PWA

Upload ALL files in this folder to the root of your GitHub Pages repository:
- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png

Then enable GitHub Pages for that repository. Open the HTTPS Pages URL once while online, then use Add to Home Screen. After the first successful load, the app shell is cached for offline use. Saved lists remain local to that browser/device.
